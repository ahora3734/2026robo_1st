# ESP32 핀 연결 및 모터 홀센서 전압 측정 가이드

메카넘휠 4개짜리 자율주행 캐리어용 정리 (Jetson Orin Nano Super + ESP32-WROOM DevKit)

## 1. 시스템 구성

| 장치 | 연결 대상 | 인터페이스 | 비고 |
|---|---|---|---|
| 모터드라이버 Cytron MD30C ×4 | ESP32 | PWM + DIR (모터당 2핀) | PWM 입력을 외부 PWM으로 바꿔야 함(점퍼). 20kHz 이하 |
| 엔코더 모터 PG42-4266-1270E ×4 | ESP32 | 홀센서 A/B (모터당 2핀) | ESP32 PCNT 하드웨어로 카운트 |
| 초음파 HC-SR04 계열 ×4 | ESP32 | TRIG 2개를 나눠 씀, ECHO 4개 | ECHO는 5V라 분압 필요 |
| 라이다 | Jetson | UART(3.3V) → USB-UART 변환기 | ESP32 핀이 모자라서 Jetson에 연결 |
| IMU | Jetson | UART 또는 I2C | ESP32 핀이 모자라서 Jetson에 연결 |
| ESP32 ↔ Jetson | USB | UART0 (GPIO1/3) | micro-ROS 또는 직접 만든 시리얼 프로토콜 |

역할 분담: **ESP32**는 모터 PID 제어, 엔코더 카운트, 초음파를 맡고, **Jetson**은 ROS2에서 센서 융합, 위치 추정, 경로 계획을 맡는다.

## 2. ESP32 핀 배치 (22핀 사용, 예비 2핀)

### 모터 / 엔코더

| 바퀴 | PWM (MD30C) | DIR (MD30C) | ENC A | ENC B |
|---|---|---|---|---|
| 앞왼쪽 (FL) | GPIO25 | GPIO4 | GPIO34 | GPIO18 |
| 앞오른쪽 (FR) | GPIO26 | GPIO16 | GPIO35 | GPIO19 |
| 뒤왼쪽 (RL) | GPIO27 | GPIO17 | GPIO36 (VP) | GPIO13 |
| 뒤오른쪽 (RR) | GPIO33 | GPIO32 | GPIO39 (VN) | GPIO14 |

### 초음파

| 신호 | 핀 | 비고 |
|---|---|---|
| TRIG_A (앞 + 뒤) | GPIO23 | 서로 반대 방향이라 동시에 쏴도 간섭이 적음 |
| TRIG_B (좌 + 우) | GPIO22 | TRIG_A와 번갈아 발사 |
| ECHO 앞 | GPIO21 | 5V → 3.3V 분압 |
| ECHO 뒤 | GPIO12 | 분압 필수(부팅 시 LOW 유지, 아래 주의사항 참고) |
| ECHO 좌 | GPIO15 | 분압 |
| ECHO 우 | GPIO5 | 분압 |

### 사용 금지 / 예비 핀

| 핀 | 상태 |
|---|---|
| GPIO6~11 | **사용 금지** (내장 플래시에 연결됨) |
| GPIO1, 3 | UART0 (USB로 Jetson과 통신) |
| GPIO0 | 예비. 부팅 모드를 결정하는 핀이라 가급적 쓰지 않음 |
| GPIO2 | 예비. 보드 LED에 연결되어 있음 |

### 핀 배치 이유와 주의사항
- **모터 PWM/DIR**은 부팅 중에 신호가 튀지 않는 핀에만 배치했다. GPIO5/14/15는 부팅 때 PWM이 잠깐 나와서 모터가 움찔할 수 있으므로 입력용으로만 쓴다.
- **GPIO34/35/36/39는 입력 전용이고 내부 풀업이 없다.** 엔코더 출력이 오픈컬렉터라면 외부 풀업 저항(4.7kΩ, 3.3V 쪽)이 꼭 있어야 한다.
- **GPIO12가 부팅 때 HIGH이면 부팅이 안 된다** (플래시 전압이 1.8V로 설정됨). 그래서 대기 중에 LOW를 유지하는 ECHO 선(분압 저항 경유)만 연결한다.
- GPIO15/5는 부팅 설정용 핀이지만, ECHO처럼 대기 중 LOW인 신호를 연결해도 문제없다.
- **ECHO 분압 예:** ECHO —[1kΩ]— GPIO —[2kΩ]— GND로 연결하면 약 3.3V가 된다. HC-SR04P 같은 3.3V 전용 센서를 쓰면 분압이 필요 없다.

## 3. MD30C 설정 메모
- 제어 방식: Sign-Magnitude (PWM으로 속도, DIR로 방향)
- 로직 입력: 3.3V / 5V 모두 가능
- PWM이 LOW이면 모터가 브레이크 상태가 됨
- 설정: PWM source 점퍼를 **EXT PWM**으로 바꿀 것
- ESP32 LEDC로 PWM 생성, 주파수는 20kHz 이하 (예: 20kHz, 10bit)
- **전류 주의:** 모터가 멈춰 걸린 상태의 전류(35.2A)가 MD30C 연속 정격(30A)보다 크다. 피크 정격은 80A(1초)라 순간적으로는 괜찮지만, 펌웨어에 정지 감지와 출력 제한을 넣는다.

## 4. 모터 홀센서 전압 측정

### 왜 측정해야 하나
PG42-4266-1270E의 홀센서 **Vcc 허용 전압과 출력 형식은 공개된 자료가 없다** (판매처 모터뱅크 상품 페이지, 상세 이미지, 기술자료 게시판 모두 확인함). 출력이 5V로 나오면 ESP32 입력핀(3.3V)이 손상될 수 있으므로, ESP32에 연결하기 전에 반드시 측정한다.

### 엔코더 커넥터 결선 (JST XHP-4)

| 핀 | 신호 |
|---|---|
| 1 | HALL SENSOR Vcc |
| 2 | HALL SENSOR GND |
| 3 | HALL SENSOR A Vout |
| 4 | HALL SENSOR B Vout |

모터 전원(Motor+ / Motor−)은 별도 단자다.

### 측정 순서 (멀티미터)
> **ESP32는 연결하지 않은 상태**에서 진행한다. 모터 전원선도 연결하지 않는다.

1. 엔코더 **Vcc에 3.3V, GND에 GND**를 연결한다.
2. 모터 축을 손으로 천천히 돌리면서 **A Vout과 GND 사이 전압**을 측정한다. B Vout도 같은 방법으로 잰다.
3. 측정 결과로 판단한다.

| 전원 | 측정 결과 | 판정 | ESP32 연결 방법 |
|---|---|---|---|
| 3.3V | 0V ↔ 약 3.3V로 바뀜 | 3.3V에서 정상 동작 | **3.3V 전원으로 직접 연결** (가장 좋음) |
| 3.3V | 변화 없음 | 3.3V에서는 동작하지 않음 | 아래 5V 측정으로 진행 |
| 5V | 0V ↔ 약 5V로 바뀜 | 푸시풀 또는 풀업 내장, 출력 5V | **분압(10kΩ/20kΩ)이나 레벨시프터 필수** |
| 5V | 0V ↔ 값이 불안정(떠 있음) | 오픈컬렉터 | 출력에 **4.7kΩ 풀업을 3.3V 쪽으로** 연결하면 직접 연결 가능 |

> 오픈컬렉터인지 애매하면, 출력과 3.3V 사이에 4.7kΩ을 달고 다시 측정한다. 0V ↔ 3.3V로 깨끗하게 바뀌면 오픈컬렉터가 맞다.

### 펄스 수(PPR) 확인
판매처가 이 엔코더의 분해능을 13PPR, 13CPR, 7CPR로 페이지마다 다르게 표기하므로 직접 확인한다.

- ESP32 PCNT를 4체배(A/B 상의 상승·하강 엣지 모두 카운트)로 설정한 뒤, **출력축(바퀴)을 정확히 한 바퀴** 돌려 카운트를 읽는다.
- 감속비 1/49 기준 예상값:

| 엔코더 분해능 | 바퀴 1회전당 카운트 (×4 × 49) |
|---|---|
| 13 PPR | 2548 |
| 7 PPR | 1372 |
